Selected Engineering Works & Architecture Teardowns

Case Study 01 • Enterprise SaaS Live Production

VyaparFlow — Intelligent B2B Billing & Inventory Management Engine

Next.js 14 React TypeScript Tailwind CSS Prisma ORM PostgreSQL Vercel

VyaparFlow is an enterprise-grade multi-tenant B2B inventory and billing SaaS platform engineered to eliminate bookkeeping bottlenecks for small and medium businesses. Built on Next.js and Prisma with a normalized PostgreSQL schema, it facilitates automated GST-compliant tax calculations, invoice generation, real-time stock alert thresholds, and high-performance financial reporting.

Case Study 02 • Cybersecurity & Distributed Telemetry Research Grade

CyberSentinel Suite — Real-Time Threat Intelligence & Packet Interception

Python Flask React Socket.IO Chrome Extensions API Snort IDS

A proactive dual-vector security suite designed to bridge client-side browser telemetry with low-level network intrusion detection. CyberSentinel pairs a Chrome Extension monitoring phishing heuristics and malicious script execution with a background Snort network packet analyzer, broadcasting live attack indicators to an interactive administrative dashboard via WebSockets.

Case Study 03 • Personal Finance & Wealth Analytics Full Stack MERN

Saturn — Modern Expense Tracker & Budget Management Application

React 18 Redux Toolkit Node.js Express.js MongoDB Tailwind CSS Chart.js JWT Auth

A full-stack expense and budget management application with interactive dashboards, analytical charts, categorized expense tracking, and real-time financial statistics. The frontend is built with React, Redux Toolkit, Tailwind CSS, Chart.js, and Axios; the backend is powered by Node.js, Express, MongoDB, and JWT authentication.

Case Study 04 • Computer Vision & Bio-Informatics Deep Learning

MRI Brain Tumor Detection System — Deep Transfer Learning Classifier

TensorFlow 2.x Keras VGG16 Pre-trained Python Flask REST API OpenCV

A convolutional neural network pipeline utilizing fine-tuned VGG16 architecture to classify axial MRI scans into tumorous and non-tumorous slices. Built with custom contrast enhancement and bilateral noise-filtering preprocessing steps, the model serves inferences through a Flask web application with confidence scoring designed to provide clinical decision assistance.
